# ScaleShow
ArduBoy Project Musical scales

- Visualizzazione scale (notazione sillabica e alfabetica)
- 20 scale: maggiore, minore, dorico, frigio, lidio, misolidio, eolio, locrio, napoletana, napoletana minore, minore melodica, minore armonica, maggiore armonica, orientale, ungherese, enigmatica, pentatonica maggiore, diminuita, toni interi, cromatica
- Pentagramma
- Play della scala intera o della nota singola

With hex file for instant upload

# Menu Info
0-AeN: scala alfabetica e sillabica<br>
1-KEY: scala e play automatico<br>
2-MAN: play manuale della nota<br>
3-PEN: pentagramma<br>
4-INF: info<br>

# Tasti
Destra / sinistra: tonica (C, Db, D...)<br>
Giu: scala successiva (Maggiore, Minore, Dorico...)<br>
Su: scala precedente<br>
B: play scala (AeN, KEY, PEN) o nota (MAN)<br>
A: cambia schermata<br>
A tenuto 3 secondi: mute<br>
